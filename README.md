## Getting Started

Once the website files are available, you can run the project locally.

1. Clone or download the repository.
2. Open the project folder.
3. Start a local development server.

```bash
python -m http.server 8000
```

Open your browser at:

```text
http://localhost:8000
```

---

## Website Deployment

The website is designed for deployment using GitHub Pages.

1. Upload the website files to the repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/ (root)`.
5. Save the settings and wait for deployment.

Planned website URL:

`https://miyabisaaf.github.io/miyabisaaf-website/`

This URL becomes available after the website is published.
