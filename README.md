# MIYABISAAF — Official Website

**Modern Finance. Limitless Possibilities.**

A premium, responsive fintech concept website in English, styled with Warm Luxury colors (`#302A25`, `#C7A77B`, `#FAF7F2`).

## Pages
- `index.html` — corporate homepage
- `solutions.html` — fintech focus areas
- `platform.html` — interactive fictional financial dashboard
- `about.html` — brand story
- `contact.html` — non-sending demo form
- `faq.html` — frequently asked questions
- `privacy.html` — demo privacy notice
- `terms.html` — demo terms

## Run locally
Open `index.html` in your browser. Internet is required for Google Fonts; fallback fonts work offline. No build tools are needed.

## Publish to GitHub Pages
Upload all files, including `assets/`, to the repository root. In Settings → Pages, deploy from `main` and `/ (root)`. Intended URL: https://miyabisaaf.github.io/miyabisaaf-website/ (once published).

## Important
This is a fictional demonstration. It is not a bank, licensed financial institution, payment processor, money transmitter, investment platform or live financial service. All dashboard balances and transactions are invented. The contact form does not send data. Replace the legal templates and establish verified contact channels before any real business launch.
